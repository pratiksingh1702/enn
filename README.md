# ENN 4D — Living Field Explorer & Sensory AI Universe

ENN 4D is a continuous particle physics engine for thought, implementing biological and field-theoretic neural dynamics:
- **Resonance**: Continuous field attraction based on 4D distance.
- **Interference**: Superposition wave combination of resonant memory vectors.
- **Amplification & Homeostasis**: Energy absorption, physical kinetic momentum, and basal metabolic floor.
- **Phase Transitions**: Living birth (novelty threshold), splitting (mitosis), merging, and pruning.
- **Sensory & Generative Text Integration**: Continuous encoding of sentences into 4D sensory coordinates with $Z$-stack temporal memory and generative nearest-neighbor recall.

---

## Project Structure

- `enn4d.py` — Core 4D living physics engine and particle universe.
- `viewer.html` — Interactive 3D WebGL / Three.js visualizer with family zooming, 3D coordinate inspection, and no glowing halation.
- `text_encoder.py` — Sensory encoding layer transforming text into $(X, Y, Z, W)$ 4D vectors.
- `text_decoder.py` — Generative recall layer converting output $Y$ vectors back to conversational responses.
- `chat_interface.py` — Interactive brain-body chat loop with universe persistence.
- `demo_chat.py` — Automated demonstration of memory formation and querying.
- `universe.json` — Serialized living universe state.
- `memory_log.json` — Persistent conversational and sensory memory log.
